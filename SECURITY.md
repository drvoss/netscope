# Security Policy

## Supported versions

NetScope is pre-1.0 software. Security fixes are applied to the latest source
revision; older revisions are not supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature when it is available.
If it is not available, open an issue asking for a private contact channel, but
do not include exploit details, credentials, private hosts, or captured traffic
in the public issue.

NetScope performs active network probes. Only use it on systems and networks
you own or are authorized to test.
